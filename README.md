# BlogSpace

BlogSpace is a simple blogging web application that allows users to register, log in, and manage blog posts.

## Features
- User registration and login
- Create blog posts
- View blog posts
- Edit existing posts
- Delete blog posts
- Store blog posts using a JSON file

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- bcryptjs
- JSON

## How to Run the Project

1. Install Node.js.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Install dependencies:

   `npm install`

5. Start the backend server:

   `node server.js`

6. Open the frontend using the method configured in the project.
